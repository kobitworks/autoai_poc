# P011 地域ラストワンマイル配送 PoC

LMD-009 の Stage A 用、サンプルデータだけで動く静的PoCです。

## 確認できること
- 配送管理者 / ドライバーの役割切替
- 配送案件一覧・配送順
- D-01 / D-02へのドライバー割当・担当変更
- 配送状態遷移（割当→集荷→配送中→到着→完了、不在、キャンセル）
- 完了・キャンセル後は管理者も通常の配送先詳細アクセスを失効
- 管理者のBreak-glass緊急参照 / 参照終了（監査イベント付き）
- 個人情報を複製しない監査イベント
- Leaflet / OpenStreetMap 地図と疑似現在地
- サンプルデータ初期化

## 安全上の前提
実個人情報、DB、外部通知、実配送、実GPS生軌跡は使用しません。Stage B の実機GPSは別途検証対象です。

## LMD-011
Stage Aレビューで確認された不足点を補完しました。通常参照失効、担当変更、キャンセル、Break-glassをサンプルデータ内だけで確認できます。DB接続、実個人情報、Stage B実GPSはこの変更に含めません。
