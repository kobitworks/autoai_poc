# P011 地域ラストワンマイル配送 PoC

LMD-009 で開始した Stage A と、LMD-012 で追加した Stage B GPS連携の静的PoCです。サンプル配送データだけで動作し、実顧客の個人情報は使用しません。

## 確認できること
- 配送管理者 / ドライバーの役割切替
- 配送案件一覧・配送順
- D-01 / D-02へのドライバー割当・担当変更
- 配送状態遷移（割当→集荷→配送中→到着→完了、不在、キャンセル）
- 完了・キャンセル後は管理者も通常の配送先詳細アクセスを失効
- 管理者のBreak-glass緊急参照 / 参照終了（監査イベント付き）
- 個人情報を複製しない監査イベント
- Leaflet / OpenStreetMap 地図
- ドライバー画面での明示操作によるブラウザGPS現在地の開始 / 停止
- GPS精度表示と現在地マーカー / 精度円
- GPS未開始時は明示的な疑似現在地表示
- サンプルデータ初期化

## GPS / プライバシー
- GPSはドライバー画面で「GPS現在地を開始」を押した場合だけ `navigator.geolocation.watchPosition` を開始します。
- 保持するのはブラウザメモリ上の最新fixだけです。生軌跡、位置履歴、LocalStorage、DBへの位置保存は行いません。
- 停止操作、管理者への役割切替、サンプル初期化、画面非表示、取得エラー時はwatchを停止して最新fixも破棄します。
- 権限拒否、位置取得不能、タイムアウト、Geolocation非対応は画面上で縮退表示します。
- 監査ログにはGPS座標そのものを記録しません。
- 現在地へ地図を移動すると、その周辺のOpenStreetMapタイル取得が発生し得ます。PoCでは経路API送信や位置履歴保存は行いません。

## 安全上の前提
実個人情報、DB、外部通知、実配送は使用しません。GPS表示は配送業務PoCの位置確認補助であり、実運用・従業員監視用途ではありません。
