## 2. GAME-071後に追加で確認できた事実

3. `orbit-switch-courier-real-input.js` はPlaywrightの `touchscreen.tap` または `mouse.click` を使用。軌道の乗換・ハブ配達は実際の運動の角度・位置を**read-only**で観測してタイミング入力し、ゲーム状態や角度を直接セットする成功ショートカットを呼ばない。

   - Phone Portrait 390×844、touch
   - Phone Landscape 844×390、mouse
   - Tablet Portrait 768×1024、touch
   - Tablet Landscape 1024×768、mouse
5. 同テストは画面外へのCanvasはみ出し、ゲーム内フィールド配置、JavaScript console/pageerror/requestfailedを判定。確認したrunはこれらの失敗なし。
