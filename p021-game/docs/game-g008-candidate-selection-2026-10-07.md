# GAME-G008 Candidate Selection — 2026-10-07

## 目的

P021「ゲーム開発」の次サイクルとして、develop上の現行ポータルをFresh-readし、既存の7ゲームとゲームループが重複しない新規PoC候補を3案比較する。

現行の公開IDは次のとおり。

- GAME-G001「1マス農園」: 農園 / 資源・時間管理
- GAME-G002「過去の自分と協力するゲーム」: 記録再生 / 協力パズル
- GAME-G003「CityCraft 3D」: 街づくり / 都市経営
- GAME-G004「VOID RUNNER」: 宇宙 / 自動シネマティック
- GAME-G005「STAR VELOCITY」: 宇宙船レース / 速度操作
- GAME-G006「風の航路 SKYBOUND」: 飛行 / 自動シネマティック
- GAME-G007「風読みグライダー」: 飛行 / スコアアタック

G004〜G007に宇宙・飛行系が続いているため、GAME-G008では意図的に地上・室内系のゲーム性を優先する。

共通前提:
- 5〜15分程度で主要な面白さを確認できる。
- 最初の30秒以内に目的・操作・最初の行動が理解できる。
- スマートフォン / タブレットを主対象とし、Portrait / Landscapeの両方へ対応する。
- キーボードを必須にしない。
- Godot 4.7.2 / GDScript / Compatibility / Web single-threadを基本とする。
- DB、ログイン、課金、有料サービス、外部APIは使わない。
- 公開候補はP021 project_rule §10の品質ゲート、4標準viewport QA、素材ライセンス管理を適用する。

## 選定結果

**GAME-G008は「影渡りステルス」を採用する。**

選定理由:
1. 現行G001〜G007に存在しない「視界・死角・タイミング」を中心にしたステルスゲームで、作例の幅を広げられる。
2. タップ主体でゲームループを成立させやすく、スマホ / タブレットのPortrait / Landscape双方へ展開しやすい。
3. 3ステージの小規模PoCでも、サーチライト周期、遮蔽物配置、任意回収物によって判断要素とリプレイ性を作れる。
4. 光錐・影・警戒色・発見エフェクトなど、重い3Dや有料素材なしでもGodot 2Dで公開向けの視覚品質を出しやすい。
5. 飛行 / 宇宙系が続いた現行ポータルに対し、地上・室内・戦術パズル寄りの体験へ明確に切り替えられる。

## GAME-G008 初期定義

- ID: GAME-G008
- 名称: 影渡りステルス
- slug: `shadow-step-stealth`
- ジャンル: 2Dステルス / 光と影のルートパズル
- 主操作: 遮蔽物のタップ移動、必要に応じて長押しで待機 / タイミング調整
- 1プレイ: 60〜90秒
- 初期PoC: 3ステージ
- 基本ループ: 配置確認 → 暗所間を移動 → サーチライト回避 → 任意情報片回収 → 出口到達 → 評価 / ベスト更新 → 再挑戦
- 成功条件: 発見されず、または許容警戒回数内で出口へ到達
- 失敗条件: 発見ゲージ上限、または制限時間超過
- 判断要素: 安全ルート vs 高得点ルート、移動タイミング、情報片を回収するかの判断
- 記録: ステージ別ベストタイム、情報片数、最高評価
- 画面対応: Phone Portrait 390x844 / Phone Landscape 844x390 / Tablet Portrait 768x1024 / Tablet Landscape 1024x768
- コスト: 無料構成。有料素材・有料APIは使用しない。素材を使う場合はCC0等を優先し、ASSETS.md / CREDITS.mdで追跡する。
