# GAME-G010 Othello — Godot redesign

Task: GAME-057

## Goal
Rebuild the existing 8x8 Othello game as a polished Godot 4.7.2 Web game while preserving the original rules and CPU-match flow.

## Gameplay
- Standard 8x8 Othello / Reversi rules.
- Player may choose first (black) or second (white).
- CPU depth presets: Easy 3 / Normal 4 / Hard 5.
- Legal-move hints can be toggled.
- Automatic pass handling and game-end judgement.
- CPU evaluation includes disc difference, mobility, corners, and edges.
- Result overlay supports immediate rematch.

## UX / quality
- Large touch-first board.
- Legal moves, last move, placed disc and flips have visual feedback.
- Generated sound effects with SOUND ON/OFF.
- Responsive portrait/landscape layout for phone and tablet.
- Keyboard helpers: 1/2/3 difficulty, S starter, M hints, R new game.
- "?qa=1" enables an automated rule-respecting finish path for CI only.
