# Credits and licenses

## Puzzle illustrations

Aurora, Harbor, Garden, and City Night are original SVG illustrations created specifically for GAME-064 / GAME-G029 and stored in `assets/`. No third-party photographs, puzzle images, CDN assets, or generated remote assets are required at runtime.

## Font

The CI workflow downloads **Noto Sans JP** from the Google Fonts repository solely for bundling into the Godot Web build.

- Family: Noto Sans JP
- License: SIL Open Font License 1.1
- Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
- The workflow copies the OFL text to the published game directory as `NotoSansJP-OFL.txt`.

## Audio

All game sounds are synthesized at runtime by GAME-064 code using simple generated waveforms. No audio files or third-party sound libraries are bundled.
