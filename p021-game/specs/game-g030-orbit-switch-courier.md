## 2. 候補3案

### A. Orbit Switch Courier（軌道切替配送）
自動で円軌道を周回する配送機を、交差点でタップして別軌道へ乗り換え、指定ハブへ荷物を届けるタイミングアクション・パズル。

- コアループ: 荷物確認 → 軌道周回 → 乗換タイミング判断 → 配達 → コンボ継続
- 操作: タップ / クリック / Space の1アクション中心
- リプレイ性: 配置・速度・配送先のseed変化、コンボ、BEST
- Godot適性: 高。2D図形、Path相当の軌道、Tween/Particleで軽量に構成可能
- モバイル適性: 高。片手操作でも成立

### B. Magnet Sort Workshop（磁力仕分け工房）
左右の磁極を切り替え、流れてくる部品を対応レーンへ誘導するリアルタイム仕分けゲーム。

- コアループ: 部品識別 → 磁極切替 → レーン誘導 → 連続正解
- 操作: 左右2ボタン
- リプレイ性: 速度上昇、部品特性、連続ボーナス
- Godot適性: 高。ただし物理挙動の調整コストがAより高い
- モバイル適性: 高

### C. Lantern Current（灯流し航路）
小さな水路の分岐板を回し、流れてくる灯籠を色別の出口へ導く短時間ルーティングパズル。

- コアループ: 流路確認 → 分岐回転 → 灯籠誘導 → 同時処理
- 操作: 分岐点をタップ
- リプレイ性: 水路配置、複数色、速度、連鎖
- Godot適性: 高
- モバイル適性: 高。ただし既存のSwitch系パズルとの印象重複がAより大きい

## 4. GAME-G030 最小仕様
- ID: GAME-G030
- slug: orbit-switch-courier
- ジャンル: タイミングアクション / 経路判断
- エンジン: Godot 4.7.2 / GDScript / Compatibility
- 対象: スマホ・タブレット・PC Web
- 1プレイ: 60〜120秒
- 主操作: タップ / クリック / Space
- 初期構成: 3〜5個の軌道、複数ハブ、配送先シンボル、配送機1体
- プレイヤーは現在の軌道上を自動周回する
- 軌道が接近・交差する「乗換ウィンドウ」で入力すると隣接軌道へ移る
- 荷物には配送先の色＋形シンボルを併記し、色だけに依存しない
- 正しいハブへ到達すると配達成功、新しい荷物を受け取る
- 誤配・乗換ミス・時間超過でエネルギーを失う
- エネルギー0または制限時間終了でRESULTへ
- スコア: 配達数を主軸に、連続配達コンボを加点
- BESTはlocalStorage相当のWeb保存を利用
- SOUND ON/OFFを用意する

## 5. 面白さの核
「いつ乗り換えるか」を瞬時に判断することを中心にする。序盤は軌道2〜3本で理解させ、進行に応じて回転方向、速度差、短い乗換窓、配送期限を追加する。単なる反射神経だけでなく、1〜2手先の経路選択が得点差になる設計を目指す。

## 6. 初期Stage 1
- 軌道3本
- 配送ハブ3種類
- 乗換点2〜3箇所
- 90秒
- エネルギー3
- 連続3配達でCombo x2、5配達でx3
- チュートリアルは開始後30秒以内に「目的・操作・最初の行動」が分かる短いオーバーレイとする

## 7. 表現
外部有料素材やAPIは使用しない。背景、軌道、配送機、ハブは独自のベクター風描画を基本とし、軌道移動時の残光、成功時の粒子、コンボ表示で視認性と達成感を出す。

## 8. レスポンシブ・品質条件
